# Standard Path

1. 运行 `python3 analyze_sample.py`，确认所有 manifest 校验和通过。
2. 记录像素尺度、恢复波束和每波束像素数，说明为什么 Jy/beam 图像积分必须除以每波束像素数。
3. 同时检查图像、残差、局部噪声图和源表，说明哪些目录项被屏蔽以及原因。
4. 使用 `halo_region.reg` 和配置的背景环计算背景扣除积分通量及总不确定度，并判断结果属于测量、候选还是上限。不得把 `3σ` 灵敏度阈值自动称为上限。
5. 分别报告随机噪声、背景零点、残差积分代理量和通量标尺误差，指出主导项。
6. 写出限制声明，说明该样本不能支持重新校准、谱指数和短间距恢复结论。

最低提交物包括脚本输出、区域与屏蔽说明、误差预算表和 5 至 8 句结论。结论必须引用数值证据。
