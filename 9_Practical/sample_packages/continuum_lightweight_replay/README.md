# Continuum Lightweight Replay Sample Package

这个轻量样本包用于本册的归档连续谱复盘练习。它不包含完整 Measurement Set，而是保留重跑图像、残差图、局部噪声图、源表、区域文件、清单、参数、任务说明和报告模板。

支持的训练目标：低面亮度连续谱上限、源表可靠性检查、产品差异审计、处理报告与限制声明。

不支持的训练目标：完整校准求解、谱指数测量、短间距恢复、精确通量标尺重新校准。

运行基础验证和区域测量：

```bash
python3 analyze_sample.py
```

脚本会核对 manifest 校验和，读取图像、残差、局部噪声图和源表，按
`halo_region.reg` 建立区域，屏蔽标记为致密源的目录项，并从配置的椭圆
背景环估计局部零点。输出包括背景扣除后的积分通量、独立波束数，以及
相关噪声、背景估计、残差代理量和通量标尺组成的误差预算。
